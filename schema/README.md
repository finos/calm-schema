# schema

This directory holds the current, in-development CALM Meta Schema — edited in place on
feature branches, with no version subfolders. It is currently empty pending the history
migration from `finos/architecture-as-code:calm/release`.

Released versions are available as git tags (e.g. `v1.2.0`) and as npm releases of
[`@finos/calm-schema`](https://www.npmjs.com/package/@finos/calm-schema), not as folders here.
